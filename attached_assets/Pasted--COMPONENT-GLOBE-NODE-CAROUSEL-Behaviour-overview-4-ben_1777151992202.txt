## COMPONENT — GLOBE NODE CAROUSEL

### Behaviour overview
4 benefit nodes rotate clockwise around the globe every 3 seconds.
Only the icon circles move between positions — all text fades out
before movement and fades back in once icons arrive.
The globe itself does not move.

━━ POSITIONS

4 fixed slots around the globe:
  Position 0 — Top
  Position 1 — Right
  Position 2 — Bottom
  Position 3 — Left

On each step, every node advances one position clockwise:
  Top → Right → Bottom → Left → Top

━━ STARTING NODE ORDER

  Slot 0 (Top):    Eliminate missorting      (sky blue icon)
  Slot 1 (Right):  Prevent overflow          (green icon)
  Slot 2 (Bottom): Collect valuable data     (navy icon)
  Slot 3 (Left):   Reduce labor costs        (gold icon)

Store nodes in a JS array. On each tick, rotate the array by 1:
  nodes.push(nodes.shift());

━━ TIMING SEQUENCE (per 3-second cycle)

  const CYCLE    = 3000;   // total ms per rotation step
  const FADE_OUT = 300;    // ms to fade all text out
  const MOVE     = 700;    // ms for icons to travel to next position
  const FADE_IN  = 300;    // ms to fade all text back in
  // Idle hold   = 1700ms  // 3000 - 300 - 700 - 300

  Phase 1 — Fade out ALL text blocks         0ms    → 300ms
  Phase 2 — Move ALL icons to next position  300ms  → 1000ms
  Phase 3 — Fade in ALL text blocks          1000ms → 1300ms
  Idle — hold, nothing animates              1300ms → 3000ms

━━ JAVASCRIPT LOGIC

  let nodes = [
    { id: 'missorting', position: 0 },
    { id: 'overflow',   position: 1 },
    { id: 'data',       position: 2 },
    { id: 'labor',      position: 3 },
  ];

  function tick() {
    // Phase 1 — hide all text
    hideAllText();

    setTimeout(() => {
      // Phase 2 — rotate array and move icons
      nodes = rotateClockwise(nodes);
      updateIconPositions(nodes);

      setTimeout(() => {
        // Phase 3 — show all text
        showAllText();

      }, MOVE);
    }, FADE_OUT);
  }

  // On page load: set initial icon positions, then show all text
  updateIconPositions(nodes);
  showAllText();

  // Start carousel
  setInterval(tick, CYCLE);

  function rotateClockwise(arr) {
    const copy = [...arr];
    copy.push(copy.shift());
    return copy;
  }

  function hideAllText() {
    document.querySelectorAll('.node-text').forEach(el => {
      el.style.opacity = '0';
      el.style.pointerEvents = 'none';
    });
  }

  function showAllText() {
    document.querySelectorAll('.node-text').forEach(el => {
      el.style.opacity = '1';
      el.style.pointerEvents = 'auto';
    });
  }

  function updateIconPositions(nodes) {
    nodes.forEach((node, index) => {
      const icon = document.querySelector(`.node-icon[data-id="${node.id}"]`);
      const pos = positions[index];
      Object.assign(icon.style, pos);
    });
  }

━━ ICON POSITION COORDINATES

  Defined relative to the globe container (globe = 320px diameter).
  Icons are 56px circles — coordinates target the icon centre.

  const positions = {
    0: { top: '-80px', left: '50%',   transform: 'translateX(-50%)' }, // Top
    1: { top: '50%',   left: '110%',  transform: 'translateY(-50%)' }, // Right
    2: { top: '110%',  left: '50%',   transform: 'translateX(-50%)' }, // Bottom
    3: { top: '50%',   left: '-30px', transform: 'translateY(-50%)' }, // Left
  };

  Adjust pixel values if globe size changes.

━━ ICON MOVEMENT TRANSITION

  Apply to every .node-icon element:
    transition: top  700ms cubic-bezier(0.4, 0, 0.2, 1),
                left 700ms cubic-bezier(0.4, 0, 0.2, 1);

  Icons are always opacity: 1 — they never fade, only move.

━━ TEXT FADE TRANSITION

  Apply to every .node-text element:
    transition: opacity 300ms ease;

  Text is anchored to its position SLOT, not to the node.
  This means the text block for each slot is fixed in place —
  only its content swaps as nodes rotate through.

━━ ENTRY ANIMATION (on scroll into view)

  Use IntersectionObserver (threshold: 0.2).
  When section enters view, add .is-visible to the section wrapper.
  Start the carousel setInterval only after .is-visible is added.

  Initial state (before .is-visible):
    Globe:          opacity: 0;  transform: scale(0.85);
    Top node:       opacity: 0;  transform: translateY(-24px);
    Right node:     opacity: 0;  transform: translateX(24px);
    Bottom node:    opacity: 0;  transform: translateY(24px);
    Left node:      opacity: 0;  transform: translateX(-24px);

  On .is-visible (CSS transitions):
    transition: opacity 0.6s ease, transform 0.6s ease;
    All → opacity: 1; transform: translate(0) scale(1);

  Stagger delays:
    Globe:       0s
    Top node:    0.15s
    Right node:  0.3s
    Bottom node: 0.3s
    Left node:   0.45s

  const section = document.querySelector('.globe-section');
  const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
      if (entry.isIntersecting) {
        section.classList.add('is-visible');
        observer.unobserve(section);
        setInterval(tick, CYCLE);   // start carousel only after entry
      }
    });
  }, { threshold: 0.2 });
  observer.observe(section);
